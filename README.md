# DormPower Bot

Модульна подійно-орієнтована система моніторингу енергоспоживання гуртожитку: Telegram-інтерфейс на Telegraf, JSON-сховище, захищений локальний HTTP-дашборд.

## Вимоги

- Node.js 18+ і npm;
- залежності Telegraf і dotenv встановлюються через npm.

## Запуск

1. `npm install`
2. Скопіювати `.env.example` у `.env` і заповнити: `BOT_TOKEN` — токен Bot API, `ADMIN_ID` — числовий Telegram-ідентифікатор, `INGEST_KEY` і `DASHBOARD_TOKEN` — випадкові 32-символьні hex-ключі, `INGEST_PORT=3789`.
3. `npm start` — бот запускається через long polling; `/ingest` і `/dashboard` доступні лише на `127.0.0.1:3789`.

Файл `.env`, каталоги `node_modules/` і `data/` до репозиторію не потрапляють.

## Тестування

`npm run test:all` виконує вісім сценаріїв `tests/check_*.js` і виводить `186 PASS / 0 FAIL`. Будь-яка невдала перевірка встановлює `process.exitCode = 1` і зупиняє подальші сценарії.

## Структура

`bot.js` — композиційний корінь (не більше 40 рядків); `handlers/` — команди й багатокрокові діалоги; `utils/` — валідація, CSV, PNG, черга повідомлень; `tests/` — сценарії перевірок.
